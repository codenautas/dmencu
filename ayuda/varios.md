Herramientas para casos puntuales. Según tu perfil vas a ver algunas de estas:

| Opción | Para qué |
| :-- | :-- |
| abrir encuesta | abrir el formulario de una encuesta por su número |
| hoja de ruta | ver las encuestas con su dirección, estado y persona asignada |
| forzar descarga encuestas DM | ver qué encuestas tiene un dispositivo para pedir que las devuelva |
| blanquear encuesta | borrar las respuestas de una encuesta (antes muestra qué se va a borrar) |
| quitar encuesta de la muestra | sacar una encuesta de la muestra |
| quitar encuestas de capa de la muestra | borrar las encuestas creadas en modo capacitación |
| pasar encuestas de capa a prod | pasar a producción encuestas cargadas en modo capacitación |
| migrar operativo | copiar datos de un operativo a otro |
| intercambiar encuestas | intercambiar los datos de dos encuestas cargadas al revés |

Varias de estas operaciones **no se pueden deshacer**. Revisá bien la vista previa antes de confirmar.
